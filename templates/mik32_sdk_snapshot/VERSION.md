## Что скопировано

Только каталоги `hal/` и `shared/` исходного пакета, структура подкаталогов
сохранена без изменений (`hal/...`, `shared/...`). Остальные файлы пакета
(`CHANGELOG.md`, `README.md`, `.piopm`, `.gitmodules`, `.gitignore`,
`package.json`) не копировались — они не нужны сгенерированному firmware-проекту.

Итого: 103 файла (без учёта этого `VERSION.md`), ~1.1 МБ.

## Назначение

Этот снэпшот — источник HAL по умолчанию (режим **Bundled**) для CMake-проектов,
генерируемых конфигуратором. У сгенерированных CMake-проектов предусмотрено три
режима получения исходников HAL:

1. **Bundled** (по умолчанию) — копия из этого каталога, без сетевого доступа
   и без зависимости от установленного PlatformIO на машине пользователя.
2. **Network** — `git clone` апстрим-репозитория во время генерации проекта.
3. **Local path** — пользователь указывает путь к своей копии SDK на диске.

## Поддержка актуальности

Снэпшот **не обновляется автоматически**. Обновлять его нужно вручную —
только при осознанном решении поднять версию SDK, которую конфигуратор
поддерживает по умолчанию (повторным копированием `hal/` и `shared/` из
новой версии пакета `framework-mik32v2-sdk` и правкой этого файла).
