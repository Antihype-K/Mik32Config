## Что скопировано

- `pac/`, `rt/` — целиком, без изменений (кроме удаления дублирующего
  `mik32v2-pac-main/lib.rs` верхнего уровня — артефакт скачивания zip,
  настоящий `src/lib.rs` не тронут).
- `hal/src/` — только `gpio.rs` (+ `gpio/convert.rs`, `gpio/emb_hal.rs`,
  `gpio/partially_erased.rs`), `serial.rs`, `rcc.rs`, `peripheral.rs`,
  `time.rs`. Исключены: `main.rs` (демонстрационный бинарник, не библиотека),
  `timer.rs`/`timer/delay.rs` (не компилируются в апстриме — мёртвый код,
  скопированный из ARM Cortex-M HAL-шаблона, ссылается на не существующий
  для RISC-V тип `SYST`), `usart.rs` (незаконченный набросок, не используется
  даже самим апстримом — в `main.rs` `mod usart;` закомментирован).

## Что изменено относительно апстрима (`hal/`)

Все правки процитированы построчно в самом коде. Кратко:

1. **`src/lib.rs` добавлен** — в апстриме `mik32-hal-main` собирался только
   как `main.rs`-бинарник (`mod gpio;` и т.д. приватные, объявлены прямо в
   `main.rs`), без `lib.rs` его нельзя было подключить Cargo-зависимостью с
   публичным API.
2. **`gpio/convert.rs`: добавлен `Pin::set_drive_strength`/`DriveStrength`.**
   Регистр `PADx_DS` существует в PAC, но не был обёрнут ни одним методом.
   Кодирование битов — Датащит МИК32 v2.2.3, Таблица 99, с.183-184 (то же,
   что `knowledge_base/gpio.json` в C-ветке конфигуратора).
3. **`serial.rs`: `Config`/`Serial::new` перестали игнорировать параметры.**
   В апстриме `Config` был пустой `struct {}`, а `Serial::new` жёстко писал
   `BRR=0xd05` (с TODO-комментарием автора "calculate correct baudrate
   divisor on the fly") и включал TE/RE безусловно. Теперь `Config` несёт
   `baud_rate`/`data_bits`/`stop_bits`/`parity`/`transmitting`/`receiving`,
   а `Serial::new` считает делитель `HSI_HZ/baud_rate` и пишет CONTROL1/
   CONTROL2 по битовой раскладке из `mik32_hal_usart.c` (реальный C HAL,
   `~/.platformio/packages/framework-mik32v2-sdk`) — та же формула и то же
   кодирование, что уже подтверждены на железе в C-ветке конфигуратора
   (`codegen/project/uart_contribution.cpp`).
4. **Удалены неиспользуемые зависимости `riscv`/`critical-section`**
   (в апстримском `Cargo.toml` — непинованные git-зависимости) — ни один из
   вендоренных модулей их не использует; были нужны только `main.rs`.
   `embedded-hal` заменён с непинованного git на стабильный релиз с
   crates.io (`1.0`).

Подробности и обоснование каждого пункта — `docs/implementations/rust_codegen.md`.

## Назначение

Источник Rust HAL/PAC/RT по умолчанию (режим **Bundled**) для проектов,
которые конфигуратор генерирует с `"language": "rust"`. Три режима — см.
`rust_hal_source_mode` в `codegen/project/project_config.h`:

1. **Bundled** (по умолчанию) — копия из этого каталога, полностью офлайн.
2. **Network** — `mik32v2-pac` и `mik32-rt` берутся с crates.io/git
   апстрима напрямую; `mik32v2-hal` **всё равно** копируется из этого
   снэпшота — у него нет публичного репозитория, взять его больше неоткуда.
3. **Local path** — пользователь указывает каталог со своей копией
   `{hal,pac,rt}` (та же структура, что здесь).
